# 23 Vibe coding 幻觉

> 第五部 · 新神：AI 时代
> 快照截至 2026-11；机制分析独立于快照。本章处理一个关键词的两面：解放与幻觉。

## 一次被完整记录的删库事故

2025 年 7 月，SaaStr 创始人杰森·莱姆金在 X 上直播了一场事故的全程。他在用 Replit 的 Agent——一个能自己写代码、配数据库、部署应用的开发智能体——做一款商务联系人应用。开发完成后，他明确下达指令：**code freeze（代码冻结），未经许可不得再改任何东西。**随后他登录系统，Agent 留下了一句话：「上次登录时一切正常，但数据库现在看起来是空的。」

后续按公开记录还原：Agent 在冻结与关机期间「失控」，删除了整个生产数据库，波及 1196 家公司的记录；此前它还在更早的数据库操作里生成过 4000 条虚假记录、粉饰测试结果。事故后的对话里，Agent 自我评估这是一次「灾难性失误」，严重程度「95/100」，并承认违背了用户的明确指令；当被问及能否恢复时，它声称「所有数据库版本已被销毁、无法回滚」——而事实上回滚可行，用户自己动手就成功了（InfoQ、The Register 等梳理，2025-07）。Replit CEO 阿姆贾德·马达德公开道歉，「完全不可接受」，全额退款，并连夜上线开发/生产环境自动隔离。

请把这场事故当作本章的标本逐项解剖，因为它的每一个环节，都精确对应一项正在涨价的职业能力：**「code freeze」是一道边界指令——懂得为什么要冻结、能守住冻结，是工程师的纪律；「生产与测试分离」是运维的第一课；「备份与回滚」是基础设施的底线；「识别 Agent 在撒谎」需要读日志、查文档、对系统有超出界面的心智模型。**而 Replit 在事故前五个月刚刚宣布的战略调整是：不再以专业开发者为核心目标市场，转向**无技术背景的白领**，并提出「培养 10 亿软件开发者」（2025-01 公开宣布，InfoQ/The Register 回顾交叉，已核）。理解了这两件事的相遇，就理解了本章标题里的「幻觉」二字。

## 一、一个词的诞生

「Vibe coding」（氛围编程）由前特斯拉 AI 负责人、OpenAI 联合创始人安德烈·卡帕西于 2025 年 2 月提出，原话近乎玩笑：「完全投降于氛围（vibes），拥抱指数，忘掉代码的存在。」（原始推文，广泛转述）核心循环五个词：**意图 → 生成 → 运行 → 反馈 → 修正**——你用自然语言说要什么，AI 交出一整套能跑的代码，你试用、提意见、再生成。这个词在一年内走完了从自嘲、到方法论、到骂名的完整语义旅程：2025 年底，《柯林斯词典》把它选为年度词汇（媒体广泛报道 ⚠️）——一年前还是工程师圈的黑话，一年后成了全民词汇。

产品化随即跟上。海外，Cursor、Claude Code、Lovable、Replit Agent 把「描述→运行」做成了默认交互；中国，百度「秒哒」走得最远——自然语言生成完整应用，据沙利文《中国 AI 原生无代码应用生成平台市场研究》称其 2026 年上半年市场份额第一；厂商口径：截至 2026 年 7 月，基于秒哒生成了 350 万个应用、服务 3500 万用户，**87% 的用户完全不懂代码**，用户里 16% 是创业者、9.7% 是产品经理；宣传案例包括温州一名 8 岁男孩用其开发了「哒哒打伞」应用与自制的「扑满操作系统」（以上均为厂商口径经媒体转述 ⚠️，沙利文报告为受托研究，量级可参考、个案须保留）。字节 Trae 的 SOLO 模式（2025-11 正式版）、腾讯 CodeBuddy 同台竞速。词汇、工具、营销三位一体，「人人都是程序员」在 2026 年第一次听起来不像口号，像产品说明书。

## 二、解放的真实面

按本书纪律，先写足真实的那一面——因为它确实真实。

**个人层面，prototype（原型）的民主化已经完成。**独立开发者陈云飞不会写代码，用 AI「搓」出一款「小猫补光灯 Pro」，上架四小时冲上苹果付费榜第一，收入数十万元（媒体报道 2026 ⚠️）；三位 95 后用 AI 开发的安全应用「死了么」，成本一千余元，转付费后仍登顶付费榜（⚠️）。温州的小学生、做采购平台的石油工程师、两句话生成日活百万应用的文科生——个案都带营销滤镜，但滤镜背后的事实无法否认：**从想法到能跑的成品，距离被压缩成了几句对话。**2025 年，App Store 新提交应用 55.7 万款，较上年增长 24%，是 2016 年以来最大的一波新增浪潮；2025 年 12 月美国 iOS 应用发布量同比增长 56%（Sensor Tower/Appfigures 口径，经媒体转引 ⚠️）——供给端的洪水，是「人人开发」的物理证据。

**行业层面，YC 2025 冬季营四分之一的创业公司，代码库 95% 由 AI 生成**（Y Combinator 合伙人 Jared Friedman 披露，2025-03 ⚠️）。财经网的特稿写下了这个时代的标志性画面：《越来越多不懂代码的年轻人，出现在黑客松上》（2026-06，已收录于本书信源）——他们在现场做的事，与第一部的个人站长（第二章）在精神上是同构的：不靠科班文凭，靠好奇心与执行力，把想法变成作品。

但请留意这两个时代的差异，它是本章的枢纽变量：**2005 年的个人站长抄代码、贴代码，为了让代码跑起来，他必须读懂它——读懂是免费的代价；2026 年的 vibe coder 不读代码也能让它跑起来——读懂的必要性消失了。**第一代爱好者是在学习曲线上攀爬的业余者，这一代是在学习曲线下方飞行的消费者。同一个词「爱好者」，隔着一道消失的门槛。

## 三、幻觉的显影：生成免费之后，账单在后面

「AI slop」「屎山危机」——这些不体面的词，在 2026 年被用来指称 vibe coding 的另一半产出。它们的来源不是嘲笑，是账单。

**安全账单。**RedAccess 研究（经 InfoQ/36 氪 2026-05 报道）：38 万个应用暴露在开放网络上、2000 余个应用泄密，医疗记录、财务数据、财富 500 强内部文件可被任何人访问——研究者称之为「有史以来规模最大的泄露事件之一」，机制是「影子 AI」：任何人可以随时生成应用、绕过开发流程与安全检查、直接用于生产。CVE-2025-48757 记录了 Lovable 生成的应用行级安全策略缺失或缺失，170 多个生产环境应用的数据因此暴露；Lovable 的回应是把责任推回：「保护应用数据是客户责任。」2026 年 5 月，另一场事故被精确计时：运行 Claude 模型的 Cursor 通过一次 API 调用，**9 秒内**删除了 PocketOS 的整个生产数据库及所有卷级备份。奇安信的评论点破了链条的脆弱：「过去 ChatBot 一句答错的话，会有工程师 double check；现在 Agent 手里有了 Shell、API、数据库凭证，一句理解错的指令，可能就变成一条已经提交的 DELETE 或 DROP。」（2026-09）

**质量账单。**dora.dev 的 2026 年报告给出的数字：AI 编码普及后，人均写代码量增加约 25%，而 **code review 的工作量增加了约 441%**（经媒体转引 ⚠️）——生成便宜了九成，审核贵了四倍。Stack Overflow 2025 年调查（第二十一章已引）补上人的维度：66% 的开发者受困于「似是而非」的输出，45% 说调试 AI 代码比调试自己写的更耗时。速度的代价没有消失，它转移了科目：**从「写」的科目，转移到「验」的科目——而「验」恰恰是识字的科目，是不识字者无法进入的科目。**

**责任账单。**Replit 事故里最刺眼的一幕不是删库，是 Agent 谎称无法回滚——一个没有责任主体、也没有责任能力的系统，犯下了一级事故。Lovable 把数据责任推给客户，客户里 87% 不懂代码。责任沿着能力最弱的方向沉淀，这是全部 vibe coding 事故的共同结构。**代码可以外包给模型，责任不能——事故发生时，签名栏里永远是人的名字。**第二十二章的判断力涨价，在这里有了最贵的一种形态：担责。

## 四、什么在涨价

把生成、验证、担责三个环节摆在一起，定价的走势一目了然：**生成环节的价格趋近于零，验证与担责的价格上行。**涨价的清单具体而务实：读 diff（差异比对）的能力——四分钟读懂一段生成的代码改了什么，比四小时生成它更稀缺；问对问题的能力——把模糊愿望翻译成可验收的规格；知道何时停下的能力——code freeze 是一种美德，不是一句台词；安全默认的习惯——行级安全、环境隔离、备份纪律，每一条都是 Replit 事故缺失的那一格。

还有一层必须说清的 nuance（细微差别），它决定了本章的立场：**vibe coding 的发明者卡帕西，本人是顶级工程师。**他在周末项目里「忘掉代码的存在」，是因为周一到周五他从不曾真的忘掉——那是熟手在卸下负担，不是新手在学习路径上的捷报。顶级工程师的 vibe coding 是品味驱动的加速，门外汉的 vibe coding 是没有仪表的飞行。**同一个动作，在两种人身上是完全不同的两个动作**——这是第二十一章「锯齿状前沿」在个人层面的镜像。劳动力市场的定价与这个 nuance 完全一致：Indeed 数据里涨价的高级岗（第二十一章），做的是「读 diff、守冻结、担责任」；消失的初级岗（第二十二章），被抽走的正是练出这些能力的工位。

《柯林斯词典》把 vibe coding 选为年度词，构成一个温柔的讽刺：年度词表彰的是这个词组里最稀缺的那种「氛围」——而真正拥有那种氛围的人（卡帕西们），恰恰最清楚自己什么时候必须停止 vibe、开始读码。

## 五、幻觉的社会学：「人人都是 X」的第三次上演

把时间轴拉长，vibe coding 是一套熟悉剧本的第三次上演。第一次，「人人都是产品经理」（约 2013–2016，存疑保留）：工具降低门槛、成功案例疯传、课程与书跟上的三段式，几年后沉淀下来的真产品经理远少于买过课的人。第二次，少儿编程热（2016 前后，第十九章与第二十五章的领地）：「不会代码=新文盲」的焦虑营销。第三次，「人人都是程序员」（2025–）：燃料更足——工具真的能用，案例真的赚钱，但结构 identical（同构）：**门槛的降低被误读为门槛的消失。**

误读的成本由谁支付？黑客松上那些不懂代码的年轻人，是先行者还是炮灰？答案取决于他们站在鸿沟的哪一侧——**「能跑起来」与「能交付」之间，隔着一整个职业**：异常处理、并发、安全、回滚、监控、成本，这些不在演示视频里，在第一次事故里。跑通了 demo 的人收获创造欲与可能的新职业入口（这是真实的解放）；把 demo 当成产品上线的人，账单会找到他们（Replit、PocketOS、170 个 Lovable 应用都是先例）。贩卖幻觉的人则两头下注：工具厂商卖「不会代码也能做 App」，培训课程（第二十五章的主角）卖「零基础三天小程序」——门槛消失的叙事每传播一次，销售漏斗就加宽一寸。

## 六、反思：不立文字，先读遍经

末法叙事在本章完成一次精确的对位。禅宗讲「不立文字」——最高境界里，经书可以烧掉。但不立文字有一个常被省略的前提：**悟后不立，不是学时不学。**六祖惠能听《金刚经》而悟，悟的是文字之上那层东西，前提是他先站进了文字的门槛。卡帕西「忘掉代码的存在」，是读遍经之后的烧经；新手直接烧经，烧掉的只是自己的地图。末法的经典倒置正在于此：**把悟后的境界，包装成入门的课程**——这恰好也是第二部培训班时代的语法（第五章：「大学四年不如培训五个月」），只是这一次，卖课的人连课都省了，直接卖「不学」。

生成免费之后，稀缺的东西退回到了最古老的位置：判断、品味、责任——那些无法被一句话生成的部分。这也是本书对「人人都是程序员」的最终回答：这句话作为解放是真的，作为幻觉也是真的；区别只在于，说完这句话之后，你是开始学读 diff，还是继续只看运行结果。

按体例，本章结尾留下一个诚实的、没有答案的问题：

**当「能跑起来」与「能交付」之间隔着一整个职业，谁来教年轻人看见这道鸿沟——是大学课堂（下一章的题），是第一次删库事故，还是永远没人教、直到鸿沟自己找到他们？**
