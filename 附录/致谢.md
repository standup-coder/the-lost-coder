# 致谢

> 本书是开源作品，v0.1 正文完稿于 2026-11-18。这一页会随版本持续补充。

**给所有留下公开记录的人。**本书的每一章都站在别人的记录上：判决书里的当事人、财报里的数字、社交平台上的自述、GitHub 上的星标、BBS 里二十年前结帖的答主、报纸上被引用的学者、以及那些写下「我受不了了」然后按下删除键的人。他们中的大多数并不认识这本书的读者——这正是「公开记录」的含义。本书全部信源已在各章「本章信源」与[参考文献](../素材/参考文献.md)中分级列明，勘误通道常年开放。

**给开源基础设施。**GitHub 与各家代码托管平台、Stack Exchange API、Wayback Machine、各百科与学术数据库——本书的事实核查与时间线整理，受益于这些公共品的可用性。

**给同路的书。**姊妹书《末法时代的胖子》（fat-looser/the-lost-fatty）与本共享「末法」框架：一本写身体的去道德化，一本写劳动的去技能化。

**给未来的受访者。**访谈计划（60–80 人）尚未启动；启动后，凡同意引用的亲历故事将在此页与正文致谢。征集通道见[CONTRIBUTING](../CONTRIBUTING.md)。

**给勘误者。**任何数据、事实、引文的错误，请通过 issue 提交；采纳者将在此页署名（可匿名）。
