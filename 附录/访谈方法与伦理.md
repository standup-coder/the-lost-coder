# 附录 · 访谈方法与伦理

> 本书计划访谈 60–80 位从业者（M1/M3 阶段执行中）。本文件是访谈执行的伦理承诺与操作规范，向受访者与读者公开。

## 一、对象与配额（目标 60–80 人）

| 人群 | 目标样本 | 核心追问 |
|---|---|---|
| 培训班学员（成功/失败/未结业） | 各 8–10 | 决策链、真实花费、就业率体感、回望评价 |
| 培训机构从业者（讲师/招生/就业老师） | 6–8 | 内部话术、就业数据口径、行业转向 AI 的过程 |
| 高校教师（计算机系/双非为主） | 6–8 | 课程时差、科研考核、学生真实去向 |
| 大厂 HR 与面试官 | 5–6 | 简历筛选真相、培训背景与第一学历的运作 |
| 外包/驻场员工 | 8 | 合同结构、身份感、跳槽路径 |
| 35+ 程序员（在职/被裁/转型） | 10 | 悬崖的真实位置、身体、家庭账本 |
| 县城与二线程序员 | 6–8 | 地理选择、远程、体制内信息化岗 |
| 女性程序员 | 8–10 | 招聘、生育、比例、社区处境 |
| 00 后新人 | 8 | 入场体验、与 AI 的关系 |

| 离开行业的人 | 8–10 | 退出决策、机会成本、是否后悔 |

## 二、伦理规范（硬约束）

1. **知情同意书面留档**：访谈前说明用途、署名方式、撤回权利，取得书面（含电子）同意；
2. **一律化名脱敏**：人物特征至少三项泛化（公司→行业、城市→区域、年限→区间），防止对号入座；
3. **可随时撤回**：受访者可在成稿前无条件撤回全部或部分内容，撤回不留痕；
4. **不付费**：不向受访者支付报酬，不承诺成书收益分成；
5. **未成年人不采访**；
6. **引用核验**：涉关键事实的口述须有至少一个独立旁证或当事人书面确认；
7. **负面断言双源**：涉及具体机构或个人的负面断言，须两个独立信源或当事人自述（与正文纪律一致）。

## 三、流程

1. 征集：通过仓库 issue 模板「亲历故事」或社区渠道报名；
2. 预沟通：确认身份范围、脱敏口径、可引用范围；
3. 访谈：线上/线下，60–90 分钟，录音须经同意；
4. 转写：整理为脱敏纪要（存 `素材/访谈/`，内部稿不直接发布）；
5. 核验：受访者确认引用段落；
6. 使用：正文引用时注明「受访者，化名」；受访者可选择公开署名（默认不署名）。
