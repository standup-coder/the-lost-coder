# 末法时代的程序员

**The Lost Coder** — 一部关于中国程序员行业的开源民族志

> 当写代码不再稀缺，程序员这个身份还剩下什么？

## 这是一本什么书

中国的程序员行业走过了手艺与觉悟同在的年代（**正法**），走过了庙宇鼎盛、修行仪式化的年代（**像法**），如今站在经文无限供应、证悟者稀缺的年代（**末法**）：教程唾手可得，AI 即问即答，但从初学者到真正手艺人的那条路，正在消失。

本书以 20 余万字、32 章、60–80 个访谈，记下这个行业的完整账本：培训班、大学、大厂、外包、35 岁、社区、开源、AI——以及那些还在业余时间写代码的人。

它不是行业唱衰的爽文，也不贩卖焦虑。每个断言都配上最强的反方证据，每个数据都标注年份、口径与来源。

## 如何参与

本书从骨架起就是开源的，三种参与方式：

1. **亲历故事**：通过 [issue 模板](../../issues/new?template=story.yml) 分享你的行业经历，经你确认后匿名写入本书；
2. **事实勘误**：发现数据、事实或引用有误，用 [勘误模板](../../issues/new?template=errata.yml) 提交，附来源优先；
3. **讨论建议**：对结构、立论、章节取舍有想法，欢迎开 issue 讨论。

所有贡献者将署名于附录致谢。

## 数据纪律

- 每个数据标注**年份与口径**，不同口径不并列比较；
- 点名机构只用三类材料：公开财报、监管问询函、判决书与正规媒体报道；
- 二手转引数据标注 ⚠️，出版前回溯原始出处；
- 人物故事默认匿名化、特征泛化，引用稿先经受访者确认。

详见 [STYLE.md](STYLE.md)。
