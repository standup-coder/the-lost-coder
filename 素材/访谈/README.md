# 素材 / 访谈

访谈是本书的骨肉。本目录存放：各人群访谈提纲、脱敏访谈记录、伦理文档。

## 伦理规范（对作者与协作者同样生效）

1. 知情同意书面留档（issue 或邮件确认均可）；
2. 一律化名脱敏，人物特征至少三项泛化（城市→城市级别、公司→公司类型、时间→年份）；
3. 受访者可随时撤回，撤回后相关素材全部删除；
4. 不向受访者付费；
5. 未成年人不采访。

## 访谈矩阵（目标 60–80 人）

| 人群 | 目标样本 | 核心追问 |
|---|---|---|
| 培训班学员（成功/失败/未结业） | 各 8–10 | 决策链、真实花费、就业率体感、回望评价 |
| 培训机构从业者（讲师/招生/就业老师） | 6–8 | 内部话术、就业数据口径、行业转向 AI 的内幕 |
| 高校教师（计算机系/双非为主） | 6–8 | 课程时差、科研考核、学生的真实去向 |
| 大厂 HR 与面试官 | 5–6 | 简历筛选真相、培训背景歧视的运作 |
| 外包/驻场员工 | 8 | 合同结构、身份感、跳槽路径 |
| 35+ 程序员（在职/被裁/转型） | 10 | 悬崖的真实位置、身体、家庭账本 |
| 县城与二线程序员 | 6–8 | 地理选择、远程、体制内信息化岗 |
| 女性程序员 | 8–10 | 招聘、生育、比例、社区处境 |
| 00 后新人（含 AI 原生代） | 8 | 入场体验、与 AI 的关系、对前辈叙事的看法 |
| 独立开发者/爱好者 | 6–8 | 收入结构、动机、对「爱好已死」的看法 |
| 开源维护者（中文项目） | 6 | KPI 开源、断供风险、社区治理 |
| 离开行业的人 | 8–10 | 退出决策、机会成本、是否后悔 |
